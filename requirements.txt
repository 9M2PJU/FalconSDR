# The app is a small web server (Python's standard library) with a browser UI
# - these are the only Python packages it needs, all with prebuilt wheels on
# Linux/Windows/macOS:
numpy>=1.26
scipy>=1.11
# Windows has no system time zone database - zoneinfo needs this package
# there (on Linux/macOS it's harmless, the system one is used first).
tzdata
# RTL-SDR without SoapySDR: pyrtlsdrlib ships a prebuilt librtlsdr (incl.
# RTL-SDR Blog V4 support) for Windows/macOS/Linux, so the dongle works with
# pip alone. On Windows the dongle still needs the WinUSB driver (Zadig) -
# the same one SDR++/SDR# already need.
pyrtlsdr>=0.3
pyrtlsdrlib
#
# Optional - SoapySDR, for non-RTL-SDR hardware (HackRF, LimeSDR, Airspy,
# SDRplay, USRP/UHD, ...). Needs a system install:
#   Linux (Ubuntu/Debian):  sudo apt install python3-soapysdr soapysdr0.8-module-<device>
#   Windows/macOS:          no pip wheel; conda-forge has soapysdr and
#                           soapysdr-module-<device> (a separate conda env -
#                           not verified end-to-end by this project).
# With no SDR library at all, the app still starts; debug mode (Settings →
# Advanced) adds a simulated receiver for testing.
#
# Optional - MP3 recording output (Settings → Recording → MP3) needs a system
# `ffmpeg` on PATH; without it the app keeps writing WAV:
#   Linux: sudo apt install ffmpeg   Windows: winget install ffmpeg   macOS: brew install ffmpeg
#
# Optional - transcription (faster-whisper + Whisper models, several GB) is
# deliberately NOT a requirement: install it from the web UI (Settings →
# Transcription & computers → Install) on whichever computer should
# transcribe. It runs `pip install faster-whisper` into the running Python,
# falling back to a `--system-site-packages` .venv only on PEP 668
# ("externally-managed-environment") systems, which main.py then re-execs
# into automatically. GPU (NVIDIA/CUDA) support adds nvidia-cublas-cu12 and
# nvidia-cudnn-cu12. See falconsdr/playback/transcription_install.py.
